**Step 1: Create toast utility** at `frontend/src/utils/toast.js`:
```js
// Simple toast utility that works with existing ToastContainer
// If ToastProvider is available, use it; otherwise fallback to console

let toastFunction = null;

export function setToastFunction(fn) {
  toastFunction = fn;
}

const toast = {
  success: (message) => {
    if (toastFunction) toastFunction({ type: 'success', message });
    else console.log('SUCCESS:', message);
  },
  error: (message) => {
    if (toastFunction) toastFunction({ type: 'error', message });
    else console.error('ERROR:', message);
  },
  warning: (message) => {
    if (toastFunction) toastFunction({ type: 'warning', message });
    else console.warn('WARNING:', message);
  },
};

export default toast;
```

**Replacement rules:**
- `alert('Failed to load...')` → `toast.error('Failed to load. Please refresh the page.')`
- `alert('Failed to save...')` → `toast.error('Failed to save. Please try again.')`
- `alert('Failed to delete...')` → `toast.error('Failed to delete. Please try again.')`
- `alert('Success!')` → `toast.success('Changes saved successfully.')`
- Always hide `err.message` from user — show friendly text only
